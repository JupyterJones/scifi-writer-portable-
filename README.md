# 🚀 SciFi Vision Studio: Portable AI Sci-Fi Video Creator

End-to-end studio for parsing speculative science fiction Markdown storyboards, generating character voice narration via **Kokoro TTS**, rendering artwork with **Stable Diffusion LCM**, and producing cinematic 1080p motion MP4 videos with dynamic Ken Burns camera motion and soundtrack mixing.

---

## ⚡ Quick Start & 1-Click Installation

### Prerequisites
* **Operating System**: Linux (Ubuntu 20.04+, Debian, Fedora, Arch, etc.)
* **Python**: Python 3.10, 3.11, or 3.12 (with `python3-venv`)
* **FFmpeg**: Required for video rendering (`sudo apt install ffmpeg`)
* **Ollama** *(Optional for AI script generation)*: [ollama.ai](https://ollama.ai) (e.g. `ollama pull scifi-writer:1`)

### 1. Clone & Install
```bash
git clone git@github.com:JupyterJones/scifi-writer-portable-.git
cd scifi-writer-portable-

chmod +x install.sh
./install.sh
```

**What `./install.sh` does automatically:**
1. Creates an isolated Python virtual environment in `./venv`.
2. Installs core dependencies (`flask`, `pillow`, `requests`, `numpy`, `kokoro-tts`).
3. Installs lightweight CPU PyTorch & Diffusers configured for multi-threaded inference.
4. Downloads AI model weights directly from official sources:
   - **Kokoro TTS Model** (`kokoro-v1.0.onnx`, 311 MB) -> `models/kokoro/`
   - **Kokoro Voice Weights** (`voices-v1.0.bin`, 25 MB) -> `models/kokoro/`
   - **Stable Diffusion LCM Checkpoint** (`dreamshaper_8LCM.safetensors`, 2.0 GB) -> `models/checkpoints/`
5. Configures runtime folders and permissions.

## 🎬 How to Run

### 1. Launch the Interactive Web Studio
```bash
./start_studio.sh
```
Open **`http://localhost:5055`** in your browser to:
* Edit storyboards or generate new ones with Ollama `scifi-writer:1`.
* Switch voices and synthesize Kokoro audio clips with one click.
* Generate or upload panel artwork.
* Select and preview from 23 bundled sci-fi soundtrack tracks.
* Render videos with Ken Burns easing and view them in the cinema player.
* Access the interactive **Visual FX Studio** at `/effects` with 17 layered real-time canvas effects.

### 2. Command-Line Rendering (CLI)
You can compile any storyboard markdown file directly to MP4:
```bash
# Render TEMPLATEv2.md to science_v2.mp4
./venv/bin/python3 build_video.py --markdown TEMPLATEv2.md --output science_v2.mp4

# Run 100% Local Stable Diffusion Pipeline (V3)
./venv/bin/python3 build_v3_local.py

# Run Staacor News Pipeline (Ollama starcor-news:1 storyboard)
./venv/bin/python3 build_staacor_news.py
```

### 3. Standalone Video FX Post-Processing
Apply sci-fi visual effects to any completed video with zero external dependencies:
```bash
# List available presets (cyberpunk, scanlines, vhs, vignette, dust, thermal, holonet, noir)
./venv/bin/python3 apply_effects.py --list

# Apply Holonet broadcast effect
./venv/bin/python3 apply_effects.py --input staacor_news.mp4 --preset holonet --output staacor_news_holonet.mp4

# Apply Cyberpunk neon grading & vignette
./venv/bin/python3 apply_effects.py --input science_v2.mp4 --preset cyberpunk
```

## 📦 How to Build the Portable AppImage

Package the entire studio into a single self-contained `.AppImage` with zero outside dependencies:

```bash
./build_appimage.sh
```

* **Output**: `./SciFi-Vision-Studio-x86_64.AppImage` (and symlink on `~/Desktop` if present).
* **Portability**: Bundles Python, PyTorch, Diffusers, Kokoro TTS, models, fonts, MP3s, and FFmpeg into an all-in-one executable that runs on any modern x86_64 Linux system.

## 🛡️ Git & Repository Architecture

Because GitHub enforces a **100 MB per-file limit**:
* AI model checkpoints (`*.safetensors`, `*.onnx`) and virtual environment (`venv/`) are excluded from Git and restored automatically via `./install.sh`.
* Rendered `.mp4` video outputs and `.AppImage` binaries are excluded via `.gitignore`.
* All 23 individual soundtrack tracks in `mp3/` are kept under 12 MB each to push smoothly to GitHub without requiring Git LFS quotas.
